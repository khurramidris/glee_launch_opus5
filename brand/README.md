# Glee brand assets

The Glee look is warm and human: a sunny yellow mark, a cream canvas, and
characters and conversation at the center instead of generic "AI" imagery.

## Files

| Need | File |
| --- | --- |
| App icon family (installers, executables, favicons) | `src-tauri/icons/` |
| In-app wordmark | `src/assets/brand/glee-wordmark-approved-512w.png` |
| Logo and symbol masters for README, website, and social images | `brand/assets/` |
| Interface icons | `src/assets/icons/*.svg` |
| Design tokens | `brand/tokens/glee.tokens.json`, `brand/tokens/glee.tokens.css` |

## Core rules

1. Use the app icons in `src-tauri/icons/` unchanged.
2. **Glee Sun `#FFC124`** is the recognition color. Use it as a fill or accent,
   not for small text on white.
3. Put **Glee Ink `#211A12`** on yellow controls.
4. Keep character art and conversation visually primary.
5. The logo may appear only in Sun, Ink, or white.

## Name and logo

The MIT license covers the source code. It does not grant permission to use the
Glee name or logo to brand a different product or a fork in a way that suggests
it is the official app.
